Contributing to Smoother Players

Contributions are welcome! If you have an idea, improvement or bug fix, feel free to submit a Pull Request.

Before contributing

Check existing Issues and Pull Requests to avoid duplicate work.

For major changes, open an Issue first to discuss the idea.

Keep changes focused and avoid combining unrelated changes.

How to contribute

Fork this repository.

Clone your fork to your computer.

Create a new branch for your changes.

Make your changes.

Build and test the project.

Commit and push your changes to your fork.

Open a Pull Request against the master branch.

Pull Request guidelines

Explain what you changed and why.

Include relevant testing information.

Keep Pull Requests focused and easy to review.

Be prepared to make changes if requested during review.

All contributions are subject to review. Submitting a Pull Request does not guarantee that it will be accepted or merged.
